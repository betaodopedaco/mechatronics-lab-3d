# Mechatronics Lab: Simulador de Mecatrónica 3D

Um simulador interativo de mecatrónica e física 3D desenvolvido com **Three.js** e **Cannon.js**. O projeto permite a criação e manipulação de componentes mecânicos e atuadores num ambiente virtual com física em tempo real, fornecendo métricas detalhadas como RPM e ângulos de rotação.

---

## 🚀 Funcionalidades

- **Simulação de Física 3D**: Integração com `Cannon.js` para gravidade, colisões e dinâmica de corpos rígidos.
- **Atuadores e Sensores**: Suporte para componentes do tipo atuador com monitorização de métricas especiais (RPM, Ângulo).
- **Interatividade**: Manipulação de objetos na cena (agarrar, mover) e controlos de simulação (pausar/continuar).
- **Visualização em Tempo Real**: Renderização fluida com `Three.js` e painel de métricas dinâmico.
- **Ambiente Flexível**: Redimensionamento automático da janela e controlos de câmara orbitais.

## 🛠️ Tecnologias Utilizadas

- **Gráficos 3D**: [Three.js](https://threejs.org/)
- **Motor de Física**: [Cannon.js](https://schteppe.github.io/cannon.js/)
- **Linguagem**: JavaScript (Vanilla)
- **Interface**: HTML5 / CSS3

## 📦 Como Executar

Basta abrir o arquivo `index.html` em qualquer navegador moderno com suporte a WebGL.

1. Clone o repositório:
   ```bash
   git clone https://github.com/betaodopedaco/mechatronics-lab-3d.git
   ```
2. Abra o arquivo `index.html` no seu navegador.
